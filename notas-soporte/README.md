# notas-soporte/

Material auxiliar de soporte para el equipo Notebox. **No es código del producto**: es documentación interna, decisiones de diseño y notas operativas que NO viajan en el paquete distribuible pero que el equipo consulta a menudo.

Esta carpeta sirve en el **Tema 22** como ejemplo de directorio adicional que se incluye en la sesión con `/add-dir`.

> Convención del curso: en un entorno real, `notas-soporte/` viviría **como repositorio hermano** del Notebox (un nivel por encima), no como subcarpeta. Para que el curso funcione con un solo `git clone`, está plantada aquí dentro. El alumno puede practicar `/add-dir notas-soporte/` igualmente para verla aparecer en `/status` como directorio incluido explícitamente.

## Contenido

| Archivo | Para qué |
|---|---|
| `decisiones-arquitectura.md` | ADRs ligeros del equipo Notebox |
| `runbook-incidencias.md` | Pasos cuando algo falla en producción |
| `convenciones-equipo.md` | Estilo de commits, naming, revisión de PR |

Total: 3 archivos, todos Markdown, fáciles de leer y citar por el agente.
