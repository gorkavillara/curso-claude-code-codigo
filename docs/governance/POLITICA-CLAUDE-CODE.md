# Política interna de uso de Claude Code

> Versión: 0.1 (borrador inicial, pendiente de revisión por el equipo).
> Aplicable a: repositorio Notebox.

## 1. Principios generales

- **Usar la IA de forma responsable.**
- **Tener cuidado con el código generado** antes de commitearlo.
- **Consultar al equipo si hay dudas** sobre cómo aplicar la política.
- **Evitar dependencias innecesarias** en el proyecto.
- **Documentar las decisiones importantes** para que queden trazables.

## 2. Qué se permite

- Generar borradores de código.
- Pedir refactors locales sobre archivos del repo.
- Generar tests cuando sea útil.
- Pedir documentación y explicaciones del código.
- Explorar el repo con prompts en el REPL.

## 3. Qué requiere revisión adicional

- Cambios significativos en el repo.
- Modificaciones al código de producción.
- Uso de la IA en partes sensibles del proyecto.

## 4. Qué está prohibido

- No leer ficheros sensibles.
- No saltarse el proceso de revisión.
- No tomar decisiones críticas solo con la IA.

## 5. Cumplimiento

El equipo se compromete a seguir esta política en su día a día. Cualquier duda o sugerencia se canaliza al tech lead.
